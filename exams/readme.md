# Exam Tickets for the Course “Operating Systems Fundamentals”

This folder contains exam tickets for preparing for the **credit test (pass/fail assessment)** in the course **“Operating Systems Fundamentals”**.

Currently, the following files are available:

## File List

| File                                       | Description                  |
|--------------------------------------------|------------------------------|
| `Tickets_basis_of_operating_systems.md`    | Tickets in Russian language  |
| `Tickets_basis_of_operating_systems_en.md` | Tickets in English language  |

## Topics Covered

The tickets cover the following sections:

- Operating system fundamentals
- Linux file system
- Working with the terminal
- File and directory management
- Users and groups
- File permissions
- Processes and process management
- Environment variables
- Input and output redirection
- Command pipelines
- File searching and text processing
- Data archiving and compression
- System monitoring
- Basics of networking
- Bash shell and scripting

The main focus is on practical Linux terminal skills.

## Purpose
